# ☕ Coffee Machine

A Python-based coffee machine simulator that allows users to select a drink, insert money, and receive their order if they have enough funds.
This project was one of my early larger Python projects and helped me practice building interactive programs, handling user input, and managing program logic.

## ✨ Features
- Drink selection system
- Money input and payment checking
- Automatic change calculation
- Resource management
- Interactive command-line experience

## 🎮 How It Works
1. The user selects a drink from the available menu.
2. The program calculates the cost of the drink.
3. The user inserts money.
4. The machine checks if the payment is sufficient.
5. If successful, the drink is prepared and change is returned.
